# Vision Navigation Robot
#### Vision navigation robot - A Raspberry Pi 5 based autonomous robot that tracks a red target in real time using computer vision.

## Overview

A Raspberry Pi 5 based autonomous robot using computer vision.

## Current Progress

- OpenCV setup
- Red object detection
- Object tracking
- Basic navigation and hardware control

## Future Goals

- PID control
- Autonomous navigation
